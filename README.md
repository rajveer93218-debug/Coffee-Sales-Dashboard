# ☕ Coffee Sales Dashboard

## 📌 Project Overview
This project presents an interactive Coffee Sales Dashboard developed using Microsoft Excel to analyze coffee sales performance across different countries, customers, roast types, and time periods.

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization

## 📊 Dashboard Features
- Total Sales Over Time
- Top 5 Customers
- Sales by Country
- Sales by Roast Type
- Interactive Filters for Order Date, Roast Type, Size, and Loyalty Card

## 🔍 Key Business Insights
1. The United States generates the highest sales of $35,639.
2. Allis Wilmore is the top customer with $317 in sales.
3. Sales fluctuate across the 2019–2022 period.
4. Four coffee roast types are compared: Arabica, Excelsa, Liberica, and Robusta.
5. Ireland and the United Kingdom generate lower sales than the United States.

## 🎯 Project Objective
To analyze coffee sales data and identify sales trends, top customers, and geographical sales performance through an interactive Excel dashboard.
